
# Explore Espírito Santo 🌄

## 📌 Sobre o projeto

Site interativo que apresenta o estado do Espírito Santo (Brasil), destacando sua cultura, turismo, gastronomia e curiosidades.

O projeto foi desenvolvido com foco em prática de Front-End, interatividade e experiência do usuário.

---

## 🚀 Demonstração

Acesse o projeto online:  
https://habia-coutinho.github.io/explore-espirito-santo/

---

## 🤓 Funcionalidades

- 🌐 Sistema de idiomas (Português / Inglês)
- 🎠 Slider de imagens automático e manual
- 🧩 Quiz interativo sobre o estado
- 🌙 Modo claro e escuro (Dark Mode)
- 📱 Layout responsivo (mobile e desktop)
- 🧭 Navegação por seções
- 🎨 Interface moderna e organizada
